# 🎬 Kiri — 30-second demo video script

**Goal:** in 30 seconds, show that a cute owl on your Mac *actually fixes your code*.
**Format:** screen recording, 1080p, vertical 9:16 crop for Reels/Shorts/TikTok, full 16:9 for LinkedIn/X/YouTube.

## Before you record
- [ ] Reset the demo bug: `~/Downloads/Kiri/kiri-demo/reset-demo.sh`
- [ ] Kiri → Choose Project → `kiri-demo`. "Can edit files" **off** (you'll switch it on on camera).
- [ ] Turn on 🔊 Speak replies, and set your Mac volume to about 50%.
- [ ] Clean desktop: hide other windows, nice wallpaper, Do Not Disturb on.
- [ ] Open `calculator.py` in your editor at the left, with Kiri at the bottom-right.
- [ ] Record with **⌘⇧5 → Record Selected Portion** (record the audio from Kiri's voice too).
- [ ] Do one practice run so Claude's first-run delay doesn't land on camera.

## Shot list

| Time | On screen | Voice-over / caption |
|---|---|---|
| **0–3 s** | Close-up of Hoot idling, blinking at the bottom of the screen. | Caption: **"I gave my Mac a coding pet 🦉"** |
| **3–7 s** | Click **▶ Run tests**. Hoot turns sad, the rain cloud appears, and it says *"Some tests failed. Want me to fix it?"* | Caption: **"My tests failed…"** |
| **7–10 s** | Flip **Can edit files** on, then click **Fix it**. Hoot puts on headphones, with sound waves. | Caption: **"…so I asked the owl."** |
| **10–18 s** | Split view: the editor line `len(numbers) + 1` changes to `len(numbers)`. Kiri's chat shows *"Fixed it! The bug was on line 7…"* | Hoot speaks the fix out loud (keep the real audio). |
| **18–23 s** | Click **▶ Run tests** again. Hoot switches to the rainbow pose, wings up, with confetti. Kiri says *"All tests passed! Nice work."* | Caption: **"Tests pass. Owl happy. 🎉"** |
| **23–27 s** | Press **⌥Space** in another app, ask with Wispr Flow: *"What should I test next?"*, and the reply is spoken. | Caption: **"Voice too — ⌥Space from anywhere."** |
| **27–30 s** | End card: app icon + the name **Kiri** + a link. | **"Kiri — a desktop pet that codes with you."** |

## Bonus shots (notch MacBooks)
- Hoot peeking out of the notch → expanding with headphones while it works → confetti in the notch when tests pass.
- On a Mac without a notch, use 🦉 menu → **Display → Notch (simulate)** to film it.
